# ChainSight 用户使用入口说明

## 1. 文档目的

本文档提供当前仓库可直接使用的运行入口、配置入口、输出入口与交接入口，帮助接手人员快速判断“从哪里开始”。

若需要完整细节，请继续阅读：

- `docs/交接文档/Refactored/setup.md`
- `docs/交接文档/Refactored/API.md`
- `docs/交接文档/Refactored/项目交接文档.md`

## 2. 你应该先看什么

### 2.1 首次接手/首次运行

建议顺序：

1. 阅读 `docs/交接文档/Refactored/项目交接文档.md` 了解版本定位与交接边界；
2. 阅读 `docs/交接文档/Refactored/setup.md` 完成环境准备；
3. 使用 `run.py` 从本地模式进行短窗口试跑；
4. 确认输出目录结构后，再进入数据库模式或回归验证。

### 2.2 想直接找常用命令

优先查看：

- `docs/QUICK_REFERENCE.md`

### 2.3 想查函数/接口/模块关系

优先查看：

- `docs/交接文档/Refactored/API.md`
- `docs/交接文档/Refactored/函数级接口与文件格式总表.md`
- `docs/交接文档/Refactored/函数上下游依赖矩阵.md`

## 3. 当前可用入口

### 3.1 代码入口

| 路径 | 用途 |
|---|---|
| `run.py` | 当前仓库统一命令行入口 |
| `src/` | 本地文件模式主代码 |
| `pgsql_db/` | 数据库模式与落库相关实现 |
| `config/` | 当前仓库内的配置样例与数据库配置文件 |
| `outputs/` | 运行输出目录 |

### 3.2 当前可直接识别的配置文件

`config/` 目录下当前可见的典型配置包括：

- `config/BC_S5.xlsx`
- `config/BC_S9.xlsx`
- `config/ChainSight 1st SIT.xlsx`
- `config/OC_Paste_S1_20251224.xlsx`
- `config/database.json`

## 4. 最小运行路径

### 4.1 本地文件模式（建议首次使用）

```bash
python run.py --config config/BC_S5.xlsx --start-date 2025-10-06 --end-date 2025-10-10
```

### 4.2 本地模式续跑

```bash
python run.py --config config/BC_S5.xlsx --end-date 2025-10-25 --resume
```

### 4.3 数据库模式

数据库模式下，交接文档中的当前标准入口为：

```bash
python run.py --config BC_S5 --start-date 2025-10-06 --end-date 2025-10-10 --use-db
```

如需显式传入数据库连接参数，请以 `docs/交接文档/Refactored/setup.md` 中第 11 节为准。

### 4.4 依赖安装

```bash
pip install -r requirements.txt
```

## 5. 输出结果去哪里看

### 5.1 本地模式输出

通常位于：

```text
outputs/<config_stem>/run_YYYYMMDD_HHMMSS/
```

其中常见子目录包括：

- `module1/`
- `module3/`
- `module4/`
- `module5/`
- `module6/`
- `orchestrator/`
- `summary/`

### 5.2 数据库模式输出

数据库模式下的运行日志与结果说明，请优先参考：

- `docs/交接文档/Refactored/setup.md`
- `docs/交接文档/Refactored/BC算法优化测试报告.md`
- `docs/交接文档/Refactored/OC算法优化测试报告.md`

## 7. 使用建议

1. 首次不要直接从长周期全量数据开始，优先用短窗口试跑；
2. 以 `src/` 作为当前主开发/主排查基础，以 `ChainSight_Dev/` 作为历史基线；
3. 若要做数据库交付或生产化验证，优先按 `docs/交接文档/Refactored/setup.md` 的数据库章节执行；
4. 若只想快速定位资料入口，请从 `docs/INDEX.md` 回到全量文档导航。
