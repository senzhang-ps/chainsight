|------|------|----------|

| **Src** | 重构本地运行版本 | `src/` |
| **DB** | 重构数据库集成版本 | `src/` + `--use-db` |

- **操作系统**: Windows 11
- **Python版本**: 3.12.9
- **数据库**: PostgreSQL 5432 + DuckDB (内存模式)
- **测试数据**: BC_S5.xlsx 配置文件
