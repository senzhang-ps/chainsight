Design Principle

Goal-driven, not model-driven

The system starts from business questions and desired outcomes, not from whatever model happens to exist.

Capability map, not universal simulator

We do not build one giant simulation engine. We build a map of simulation capabilities with different scope, resolution, maturity, and runtime cost.

Requisite variety with bounded complexity

The system must be diverse enough to match supply chain complexity, but its engineering primitives must remain few and controlled.

Explicit assumptions and confidence

Every result must carry its assumptions, boundary conditions, and verdict quality.

Quantification, evaluation, selection

The Goal Simulation Layer does not operate the business. It evaluates possible goals, policies, and strategic choices, then selects or recommends the preferred one.

Human-in-the-loop for semantic trade-offs

When business trade-offs cannot be meaningfully reduced to formulas or weights, the system asks for human judgment.

POC Demo · Foundation Layer

Self-Evolution System + Admin Dashboard

Foundation capabilities from chainsight_intro.html: memory capture, recall, consolidation, proposal approval and admin operations.

Self-Evolution Flow

1

Capture

Tool results → observation / pitfall; user conversation → feedback; explicit agent write → memory_write. Each memory includes structured context and ontology anchors.

2

Store

cognition.db stores episodic → semantic → procedural memories. Types include pitfall, method, observation, feedback and deviation.

3

Recall

Three-path retrieval: exact ref match, ontology one-hop expansion and FTS5 keyword fallback, with salience scoring.

4

Consolidate

Session-end 10-stage pipeline promotes, deduplicates, detects new concepts / metadata, extracts rules, tracks coverage and distills knowledge.

S1 graduateS2 dedupS3 detect_newS4 detect_metaS5 extract_rulesS6 link_sourceS7 deviationS8 track_covS9 skill_learnS10 distill
5

Approve & Apply

Low-risk proposals can be auto-approved. High-risk new_class / new_edge / new_rule proposals require human review before writing JSON-LD / YAML.
