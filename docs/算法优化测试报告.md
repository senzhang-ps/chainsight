### 4.2 数据验证方法

#### 4.2.1 数值对比算法
```python
def compare_dataframes(df1, df2, tolerance=1e-10):
    """
    对比两个DataFrame的数值一致性
    """
    # 1. 结构对比：行数、列数、列名
    assert df1.shape == df2.shape
    assert list(df1.columns) == list(df2.columns)
    
    # 2. 数值对比
    for col in df1.columns:
        if pd.api.types.is_numeric_dtype(df1[col]):
            # 数值列：使用误差阈值对比
            diff = abs(df1[col] - df2[col]).max()
            assert diff < tolerance
        else:
            # 非数值列：精确对比
            assert (df1[col] == df2[col]).all()
```

| 列名一致 | 列名称和顺序完全相同 |
| 数值一致 | 数值差异 < 1e-10 |

## 5. 技术优化详解

### 5.1 代码架构优化

| 优化项 | 优化前 (Dev) | 优化后 (Src/DB) |
|--------|-------------|-----------------|
| **代码结构** | 单文件混合 | 模块化分层 |
| **数据处理** | 逐行操作 | 向量化批处理 |
| **内存管理** | 多次复制 | 原地操作 |
| **I/O操作** | 同步阻塞 | 批量写入 |
| **数据存储** | 纯文件 | 文件+DuckDB |

### 5.2 模块级优化

#### Module 1 订单生成 (5.21x 加速)
- 使用 NumPy 向量化操作替代循环
- 预计算订单分布概率
- 批量生成随机数

#### Module 3 流量计算 (1.39x 加速)
- 优化图遍历算法
- 使用稀疏矩阵存储流量
- 并行计算独立路径

#### Module 5 部署规划 (4.69x 加速)
- 预排序减少查找时间
- 使用堆结构优化调度
- 批量更新库存状态

### 5.3 DB版本额外优化
- DuckDB 列式存储，查询速度提升
- 增量数据处理，避免重复计算
- 内存映射文件，减少I/O开销
