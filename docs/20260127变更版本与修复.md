### 2.2 `(material, location)` 元组键不匹配 (前次会话修复)

**问题描述:**  
重构代码中多处使用单一 `location` 作为 `location_layer_map` 的键，而原始逻辑使用 `(material, location)` 元组作为键。

**影响模块:**
- Module 1 (Layer Assignment)
- Module 3 (MRP Simulation)  
- Module 5 (Deployment Planning)

**修复的文件 (共6个):**

#### 文件 1: `src/modules/mrp_planning/layer_assignment.py`
```python
# 修复前
location_layer_map[location] = layer

# 修复后
location_layer_map[(material, location)] = layer
```

#### 文件 2: `src/modules/mrp_planning/lead_time.py`
```python
# 修复前
layer = location_layer_map.get(location, 0)

# 修复后
layer = location_layer_map.get((material, location), 0)
```

#### 文件 3: `src/modules/mrp_planning/mrp_simulation.py`
```python

```

### 2.3 Module5 级联失败

**问题描述:**  
当 Module1 因元组键问题失败时，后续模块 (特别是 Module5) 会因缺少输入数据而产生 `KeyError`。

**根本原因:**  
Module1 的 `location_layer_map` 构建失败导致下游所有依赖该数据的模块无法正常运行。

**解决方案:**  
修复 Module1 中的元组键问题后，级联问题自动解决。
